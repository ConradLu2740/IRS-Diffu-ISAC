## 2. 预判审稿质疑与回复弹药（response letter 预写）

### Q1「这只是把 rectified flow 换了个观测场景」

回复要点（按优先级）：
1. **场景使 FM 的两个优势同时成为必需而非便利**：机载感知节拍要求少评估（数百次 NFE 不可用），同时测量值是最有价值的边信息——两个约束在空间 ISAC 设定里同时成立，这正是选 FM 而非其他生成模型的原因，不是任意替换。
2. **贡献是量化，不是生成模型**：既有生成式雷达感知工作把"条件有用"当作默认假设；本文把 measurement-to-shape 信道当作可测量对象（Δ(0)=0.302 = 6× 预注册阈值、21.8% 条件解释方差、数据级 ρ 审计、ISAR 增量的 matched-budget 隔离）。"首次量化"是本文的识别度所在。
3. **一步最优性定理 + 实测 bias–variance 前沿**：把 mode collapse 从缺陷重述为 Bayes 最优，并用两轴蒸馏前沿定位实用工作点——这是理论-实验闭环，不是"换个观测跑一遍"能带走的。
4. **系统级闭环收益**：形状先验替换手工盒子先验，感知达成率 0.840→0.932（+10.9%），生成基元在系统指标上兑现，不止于指标分。

### Q2「这是 sensing，还是从先验里采样？」（ρ≈−0.015 + 功率门结论的合击）

回复要点：
1. **论文自己先说了这个边界并量化它**（VI-C 数据级审计、Conclusion）：最近条件对的 GT 点云仍相差 0.663 raw / 0.0265 centroid-aligned CD——真实条件多样性存在，被一步图丢弃。诚实报告边界本身就是贡献。
2. **成对判别力 ≈0 与条件估计的价值不矛盾**：ρ 度量的是条件距离与形状距离的**成对秩相关**（数据级、模板库内）；而条件均值的价值体现在**条件 MMSE 的下降**（Δ(0)=0.302、21.8% 方差解释、CFG 单调改善 0.3060→0.2664）——信息在条件期望里，不在成对距离里。两者可以同时成立，审稿人若混为一谈，这是标准答复。
3. **生成式先验正是病态逆问题的求解机制**（III-B）：延迟投影是多对一映射，确定性逆不存在；先验的作用是消歧，而条件的作用是在先验内锁定与测量一致的那个区域。信道量化（第 2 点）证明后者非空。
4. **结论段的负方向表述是贡献不是缺陷**："进一步条件增益需要新观测量的新先验，而非更好的采样器"——告诉社区感知信息在哪里，这本身就是 agenda 级结论。
